# sources/ — material bruto de Jesus Cristo, Escrituras e estudo bíblico

Esta pasta recebe material que o usuário deseja incorporar: notas, textos, PDFs, ePubs ou transcrições. O pacote público contém apenas este guia; as referências curadas estão em `../references/`.

O agente não lê material bruto em conversas normais. Para incorporar uma fonte, peça explicitamente: "ingere este arquivo na skill". Siga `../INGEST.md`: ler, extrair o que é durável, atualizar a referência apropriada e registrar a procedência.

Uma biblioteca pessoal externa é opcional. Indique o caminho do material quando necessário; não publique documentos pessoais ou textos integrais protegidos junto da skill.
