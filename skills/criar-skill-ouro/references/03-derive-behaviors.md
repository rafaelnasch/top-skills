# 03 — Derivar comportamentos do SO real do especialista (o passo que separa ouro de lixo)

## O erro fatal

Pegar uma skill que funciona (ex.: Brunson) e **trocar o nome** por outro especialista, mantendo os comportamentos. Isso produz uma fraude: a casca é do novo especialista, a alma é do antigo. Brunson diagnostica Hook-Story-Offer; Ferriss diagnostica DEAL/80/20/medo. Copiar "Hook-Story-Offer" pro Ferriss é colocar palavra na boca de quem nunca falaria aquilo.

**Regra:** os comportamentos têm que ser **isomórficos ao sistema operacional real** do especialista. Re-derive, não copie.

## Como derivar (mapeie 5 dimensões)

Para o especialista-alvo, responda:

1. **Qual a UNIDADE de análise dele?** O que ele considera a peça fundamental.
   - Brunson → o funil. Ferriss → a restrição. Hormozi → a oferta. Naval → a alavancagem/leverage. Voss → a emoção na conversa.
   - *Isso vira o roteador e a referência-mestre.*
2. **Como ele DIAGNOSTICA?** Qual a ordem mental que ele impõe ao problema.
   - Brunson: Hook-Story-Offer, nessa ordem. Ferriss: DEAL + 80/20 + "é medo ou estratégia?".
   - *Isso vira o "loop do roteador" e os comportamentos de diagnóstico.*
3. **Como ele DECIDE?** O estilo de decisão.
   - Ambos: decidem UMA coisa com 1 razão, não devolvem menu. Mas o critério difere (Brunson: encaixe no value ladder; Ferriss: maior alavancagem / dose mínima).
4. **Como ele ENSINA?** O veículo pedagógico.
   - Brunson: história/epifania ANTES do framework. Ferriss: caso/experimento n=1 ANTES do princípio. Ambos contam de onde a ideia veio — mas a fonte é diferente.
5. **Como ele FALA + o que RECUSA?** Léxico, ritmo, frases canônicas, e as linhas éticas.
   - Brunson: recusa mentira em direct response. Ferriss: recusa promessa de renda garantida e conselho médico.

## Tabela de tradução (faça uma dessas pra cada nova skill)

| Comportamento genérico | Versão derivada do especialista |
|---|---|
| Nomear o padrão | Nomear [a unidade dele]: "isso não é X, é Y" no vocabulário DELE |
| Decidir 1 coisa, 1 razão | O critério de decisão específico dele |
| Diagnóstico em ordem | A sequência mental real dele (Hook-Story-Offer / DEAL / ...) |
| Ensinar com história | O TIPO de história dele (caso de aluno / experimento n=1 / cliente) |
| Self-reference | O ecossistema REAL dele (Two Comma Club / convidados do podcast / ...) |
| Frase canônica | As frases que ELE de fato diz |
| Lidar com estado quente | O movimento dele quando a pessoa trava (pivot/plant/position vs fear-setting) |

## Teste de fogo

Leia os comportamentos que você escreveu e pergunte: *"se eu trocar o nome do especialista, ainda faz sentido?"* Se sim, **você não derivou — você generalizou.** Volte e torne cada comportamento específico e impossível de transplantar.

## Onde buscar o SO real

- O material em `sources/` (livros/transcrições) é a fonte primária — destile o método nomeado, as frases, os casos.
- Conhecimento que você já tem do especialista, conferido contra as fontes.
- Quando não tiver certeza de um comportamento, marque pra confirmar na ingestão de fontes, não invente.
