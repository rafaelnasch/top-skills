# Extrair skills de trabalho que já funciona

Parta de uma execução, código ou artefato validado. Identifique decisões, passos recorrentes, formatos, correções e exceções; então transforme isso em instruções reutilizáveis.

Exemplos empacotados devem vir de resultados que foram conferidos. A existência de um template ou de uma instrução não demonstra que ele funciona. Preserve o contrato de entrada e saída e verifique se a skill continua compatível com outras capacidades usadas na mesma tarefa.

## Procedência

Edição metodológica de uma nota de estudo sobre a trilha AI Driven Development, de Leonardo Leitão (Formação.Dev). Atribuição às ideias da trilha; não é uma transcrição nem uma exigência normativa do padrão aberto. Para o formato, consulte [Agent Skills](https://agentskills.io/specification).
