# Skills com escopo coerente e composição

Uma skill deve resolver uma unidade de trabalho reconhecível, com entradas, saídas e limites claros. Separar critérios independentes permite usar um sem carregar todos e facilita o reuso.

Uma composição útil combina contexto compartilhado, análise por critérios e uma síntese final. Evite tanto a skill que tenta resolver tudo quanto fragmentos tão pequenos que exigem muitas ativações para uma tarefa simples.

## Procedência

Edição metodológica de uma nota de estudo sobre a trilha AI Driven Development, de Leonardo Leitão (Formação.Dev). Atribuição às ideias da trilha; não é uma transcrição nem uma exigência normativa do padrão aberto. Para o formato, consulte [Agent Skills](https://agentskills.io/specification).
