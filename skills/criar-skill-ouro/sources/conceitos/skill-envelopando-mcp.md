# Procedimento em torno de uma ferramenta

Uma skill pode organizar o uso de uma ferramenta: coletar parâmetros, verificar pré-condições, explicar opções e conferir o resultado. A ferramenta oferece acesso ou execução; a skill define como usar essa capacidade no tipo de tarefa esperado.

Não presuma que a instalação da skill também conectou contas ou concedeu permissões. Diga quais acessos são necessários e confirme o estado real antes de executar.
