# Description como gatilho

A descrição da skill é apresentada antes do corpo completo. Por isso precisa dizer o que a skill faz e em quais intenções deve ser acionada. Uma descrição vaga dificulta a descoberta; uma descrição ampla demais provoca ativações indevidas.

O acionamento indireto depende de julgamento do modelo. Para uma tarefa em que a escolha da skill importa, uma invocação explícita reduz ambiguidade. Compare consultas que deveriam acionar, consultas que não deveriam e casos parecidos com escopo diferente.

## Procedência

Edição metodológica de uma nota de estudo sobre a trilha AI Driven Development, de Leonardo Leitão (Formação.Dev). Atribuição às ideias da trilha; não é uma transcrição nem uma exigência normativa do padrão aberto. Para o formato, consulte [Agent Skills](https://agentskills.io/specification).
