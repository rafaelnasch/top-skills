# Fontes de Criar Skill Ouro

Biblioteca de aprofundamento em arquitetura, autoria e avaliação de skills. Contém o estudo amplo do padrão aberto, a ficha das fontes públicas e edições metodológicas de conceitos. As instruções executáveis e os templates continuam em `../references/` e `../templates/`.

As cópias são edições para consulta: metadados de acervo, aplicação empresarial, identidade pessoal, caminhos privados e transcrições de curso foram excluídos. Notas datadas representam o levantamento original, não uma atualização de todos os fatos do ecossistema.

## Como ler

Para aprofundar o formato, comece no estudo e na ficha do padrão; para uma decisão pontual, abra somente o conceito necessário. A documentação pública ligada na ficha é a referência normativa.
