# Book to Skill

Converte livros e documentos em skills estruturadas. Este pacote reúne o `SKILL.md`, o extrator, os módulos Python, os validadores e os avisos de segurança necessários para o uso.

Projeto original: [virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill). Licença MIT, preservada em `LICENSE.md`. A versão do pacote Python incluído é 1.4.0.

Use `/book-to-skill` e indique o documento. O agente segue as instruções de instalação e de extração do `SKILL.md`. Dependências variam por formato; Python 3.9 ou superior é necessário. Esta distribuição não inclui livros, resultados de conversão, testes, avaliações nem mídia de demonstração do projeto original.
